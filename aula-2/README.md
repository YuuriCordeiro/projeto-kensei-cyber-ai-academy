# Semana de Projetos em Python

## Projetos

- **Saudação com nome em maiúsculo**: pede o nome do usuário, valida a entrada e exibe a saudação em letras maiúsculas.
- **Conversor de temperatura**: converte Celsius para Fahrenheit e Fahrenheit para Celsius com menu e validação de entrada.
- **Lista de compras**: permite adicionar, ver e remover itens de uma lista de compras e salva os dados em um arquivo JSON.
- **Quiz de cyber**: apresenta 5 perguntas sobre cybersegurança, embaralha as questões e mostra feedback imediato.
- **Gerador de senhas**: cria senhas com opções de tamanho, maiúsculas, números e símbolos, garantindo ao menos um caractere de cada tipo selecionado.
- **Organizador de arquivos**: move arquivos para pastas por extensão, ignora arquivos ocultos e mostra um resumo das movimentações.
- **Monitor de sistema**: exibe uso de CPU e memória em tempo real com alerta quando a CPU passa de 80%.

## Aprendizados

- Como ler e validar entradas do usuário em Python.
- Como trabalhar com arquivos JSON para persistência de dados.
- Como usar `random` para embaralhar e gerar conteúdo aleatório.
- Como organizar arquivos com `os` e `shutil`.
- Como monitorar recursos do sistema com a biblioteca `psutil`.
- Como criar scripts simples e diretos para pequenas ferramentas úteis.
