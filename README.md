# Projeto Kensei Cyber AI Academy

## Descrição

Este repositório é dedicado ao desenvolvimento de soluções em **Cibersegurança com Inteligência Artificial**. Aqui você encontrará ferramentas, scripts e projetos educacionais que exploram a intersecção entre segurança cibernética e inteligência artificial.

O objetivo deste projeto é fornecer recursos práticos e exemplos de código para aprender e implementar técnicas avançadas de proteção, detecção de ameaças e análise de segurança utilizando IA.

## Conteúdo

- **aula-2/**: Exercícios e projetos da segunda aula
  - Scripts Python para cibersegurança
  - Ferramentas de análise e monitoramento
  - Gerador de senhas seguras
  - Quiz de cibersegurança
  - Utilitários diversos
  
- **aula-3/**: Engenharia de Dados e Visualização de Ameaças
  - **ETL Pipeline**: Limpeza e normalização de logs de ataques cibernéticos.
  - **Análise Estatística**: Identificação de tendências e volumetria de ataques.
  - **Data Viz**: Geração automática de dashboards em PNG (Top 10 países, tendências temporais e distribuição de ameaças).

## Tecnologias

- Python 3
- Pandas (Manipulação de dados)
- Matplotlib (Visualização de dados)
- Inteligência Artificial
- Análise de Segurança
